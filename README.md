# proximity — поиск дублей и похожих папок

Локальное приложение (Python + FastAPI + HTML/JS) для разбора большой фототеки:
находит полностью идентичные файлы и пары похожих папок.

## Запуск

```bat
pip install -r requirements.txt
python app.py
```

Открыть в браузере: **http://127.0.0.1:8765**

Корень сканирования задаётся в GUI или через переменную окружения `PHOTO_ROOT` (создайте файл `.env` по образцу `.env.example`). По умолчанию используется `~/Pictures`.

## Что делает

### 1. Дубликаты
- **Идентичные байт-в-байт** — SHA-256 всего файла (быстрый отсев по размеру).
- **Совпадающие метаданные EXIF** — размер + ширина/высота + время съёмки + камера + объектив + ISO + выдержка + диафрагма + фокусное.

Для каждой группы можно выбрать, какой файл оставить (остальные считаются «мусором» и учитываются в экономии места). Выбор сохраняется в браузере и экспортируется в CSV.

### 2. Похожие папки
Сравнение по **набору имён файлов** (без учёта регистра):

```
сходство = общих_имён / min(кол-во_в_A, кол-во_в_B)
```

Участвуют **только папки, в которых файлы лежат непосредственно**: состав папки — это файлы прямо в ней, содержимое вложенных папок наверх не поднимается. Папки без файлов ни в каком сравнении не участвуют, а пары «родитель ↔ вложенная папка» не формируются. Пересчёт состава из таблицы `files` происходит автоматически при старте, если в кэше данные прежней логики.

По умолчанию показываются пары со сходством > 50% и минимум 1 общим файлом. Порог и минимальное число общих файлов настраиваются в GUI. Экспорт в CSV.

### 2a. Подъём на уровень выше (кнопка «⬆ ур.»)

У каждой пары есть кнопка **«⬆ ур.»**: она сравнивает уже родительские папки A и B — причём **рекурсивно**: состав каждого родителя — это все его файлы и файлы всех его подпапок на любую глубину. На верхнем уровне видно сходство двух «деревьев» папок целиком, а ниже перечислены **группы схожих подпапок** между деревьями (например, `A/2023 ↔ B/2023`, `A/2024/Лето ↔ B/2024/Лето` и т.д.) — порог и минимальное число общих файлов берутся из тех же контролов. Результат кэшируется в SQLite до следующего скана; кнопкой «⬆ ещё на уровень» можно продолжать подниматься, пока не будет достигнут корень сканирования. Подъём работает и для папок, которых уже нет на диске (например, переименованных после скана): сравнение берётся из кэша, а в интерфейсе показывается предупреждение.

### 2b. Устаревшие папки удаляются автоматически

Когда папка уже разобрана (например, вы удалили дубликаты на диске и папка B исчезла), пара может оставаться в выдаче — её данные ещё лежат в кэше. Нажмите **«📁 A»** или **«📁 B»**: если папки нет на диске, приложение сообщит об этом и автоматически удалит её путь (вместе с подпапками и файлами) из кэша. Устаревшая пара исчезнет из выдачи и больше не появится. Кэш «расширенных» сравнений при этом сбрасывается.

## Как это устроено

- `app.py` — backend: сканирование, хеширование (8 потоков), SQLite-кэш (`scan_cache.db`), REST API.
- `static/index.html` — одностраничный GUI без внешних зависимостей.
- Сканирование идёт в фоновом потоке; прогресс виден в шапке и через `/api/status`.
- Повторный запуск скана пересчитывает всё заново (кэш по файлам остаётся, но группы строятся по последнему скану).

## API (кратко)

| Метод | Путь | Описание |
|---|---|---|
| GET | `/api/status` | фаза и прогресс сканирования |
| POST | `/api/scan` | запустить сканирование |
| GET/POST | `/api/config` | корень каталога |
| GET | `/api/duplicates?mode=hash\|meta&min_size=&ext=&q=` | группы дублей |
| POST | `/api/export/duplicates` | CSV-экспорт (body: `{"keep": [file_id, ...]}`) |
| GET | `/api/folders?threshold=0.5&min_common=1` | пары похожих папок |
| POST | `/api/folders/expand` | сравнение «на уровень выше»: `{"a","b","threshold","min_common"}` — родительские папки рекурсивно + группы схожих подпапок |
| POST | `/api/open-folder` | открыть папку в проводнике (body: `{"path": "..."}`, только внутри корня); если папки нет на диске — её путь удаляется из кэша |
| GET | `/api/export/folders` | CSV-экспорт пар папок |
| GET | `/api/file/{id}/raw` | файл для предпросмотра |

## Безопасность

Приложение только **читает** файлы и каталог — ничего не перемещает и не удаляет.
Удаление дублей вы делаете вручную (или по экспортированному CSV).
Из локального кэша удаляются только записи о путях, которых больше нет на диске.
